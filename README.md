### 程式設計能力檢定題庫

## b003. 多組數字的反轉

### 內容
輸入未知列數的數字，每一列可能包含任意數目的數字。請讀取各列輸入的數字，將該列的數字進行反轉後輸出。

### 輸入說明
輸入有多筆測資，每一列為一筆測資，每筆測資有多個整數，直到輸入 -9999 才停止。（-9999 那一列不處理）

### 輸出說明
輸出該筆測資之對應訊息於一列並換行。

### 範例輸入 #1
-85
75 -47 9 -36 63 18 34 -43
-67 -63
92 -80 65 -98 -6 8 49
76 -6 37 -25 -63 -60 22 94 -51
-9999

### 範例輸出 #1
-85
-43 34 18 63 -36 9 -47 75
-63 -67
49 8 -6 -98 65 -80 92
-51 94 22 -60 -63 -25 37 -6 76

## 解答
``` C++
#include <iostream>
using namespace std;

int main(){
    string s;
    string output[100];
    cin >> s;

    int i = -1;

    while (s!="-9999"){
        i++;
        output[i] = s;
        cin >> s;
    }

    while (i>=0){
        cout << output[i] << " ";
        i--;
    }
    return 0;
}
```
